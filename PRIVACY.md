# JellyVision Privacy Policy

JellyVision is a Roku client that connects directly to the Jellyfin server chosen
by the user. It has no developer-operated backend, advertising system, analytics,
or telemetry service.

JellyVision stores the configured server address, app preferences, and—when the
user enables saved sign-in—login or session information in the Roku device's
local registry. It sends authentication, library, playback-information, and
streaming requests only to the configured Jellyfin server. Ghost Mode can
suppress optional playback activity reports, but requests required to load and
play media are still sent to that server.

The configured Jellyfin server and the Roku platform may process information
under their own privacy policies. Users should consult their server operator and
Roku for details. Questions about JellyVision can be filed at
<https://github.com/alanoctua/jellyvision/issues>.
